Server Logs Button — 4 UI Variants

Each variant adds a logs icon button per server row. Clicking it opens server logs in a different way. The button appears in the c-acts column (rightmost) for running servers, using the terminal-2 icon.

Variant 1 Integrated Terminal ~50 lines

Click the logs button → opens a VS Code integrated terminal running tail -f on the server's log file. Native terminal with scrollback, search, selection. Each server gets its own terminal tab.

Variant 2 Inline Console (xterm.js in dashboard) ~150 lines

Click the logs button → opens the existing console surface (full-body xterm.js terminal below the grid), same as stage/agent logs. Reuses the existing openTerminal() pattern with a new server-log-request message type.

Variant 3 Dedicated Logs Panel (separate webview) ~400 lines

Click the logs button → opens a new webview panel (like Diffs or Usage) with a dedicated log viewer: search bar, ANSI color rendering, download button, auto-scroll toggle. Multiple panels can be open for different servers.

Variant 4 Combined Logs View (all servers, tabbed) ~500 lines

Click "Show server logs" in the panel header → opens a combined view with tabs for each server + a "Merged" tab showing all servers interleaved by timestamp. Best for multi-service tickets.
