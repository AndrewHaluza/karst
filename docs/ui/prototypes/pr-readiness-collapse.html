Rules

ItemRule
When2 or more bad/warn reasons: one closed disclosure. 1 reason: the T1064 row with no outer disclosure; its list collapses.
Summary itemsOne for each bad/warn reason: state icon + short label + count. The host words the text (prMergeReadiness), the TSX only places it. The icon carries the state, not colour alone (UI-R28).
ActionsEach reason action shows on the summary line, in reason order. A click on an action does not toggle the disclosure. Inside the open body, the action is not repeated.
Auto-fixA reason in a running auto-fix round shows its run state in the summary item and has no action (T1064 section 4).
Open stateClosed by default. Keep the choice for each repo across re-renders (as mergeOpen does today).
NarrowSummary items wrap; the action group goes on its own line below the items.
