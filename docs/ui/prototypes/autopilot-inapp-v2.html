Autopilot

What karst does when a shipped PR hits a problem it knows how to fix. Autopilot never merges a PR. Each ticket can override this from its ship panel.

Processing mode

Project default for every ticket and its sub-tasks.

On: karst runs the fix with the ticket's agent, up to the limit, then asks you. Off: every problem waits for your approval.

Merge conflicts

The PR no longer merges cleanly into its base.

Resets when the base branch moves.

CI failures

A check failed on the PR.

Resets when a different check fails.
Checks karst may fix
lint ×typecheck ×test:unit ×+ add
Any other check always asks.

Push diverged

Someone else pushed to the ticket branch.

When it happensAlways asks. Another person's commits are on origin, so you choose Integrate or Overwrite remote.
