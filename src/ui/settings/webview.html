Archive done tickets after
Days a ticket stays visible at done before Karst archives it automatically. The archive runs on a periodic sweep, so the delay is approximate. Blank = the 3-day default; a done ticket is never archived immediately.
Debug logging
Verbose [driver]/[gate]/[agent]/ [runtime] lines in the Karst output channel, kept in memory for issue reports. Off by default; off means logger.debug() is a no-op. Debug entries are redacted like every other log line.
Close done terminals with ticket
When a ticket is archived, also close its agent terminals whose process has already exited (VS Code marks them Done), instead of leaving the dead tabs in the terminal panel. A still-running session is never touched. Off by default.
Show changes in Source Control
Show a ticket's changed files in the IDE's Source Control view — collapsible groups per worktree and per commit — instead of opening the Ticket changes panel. Clicking a file opens the same diff either way.

Pull request description template
