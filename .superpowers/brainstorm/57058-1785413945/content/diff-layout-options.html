A — Dedicated change explorer + native diff editor

“Diff” opens a focused Karst tab. The left side groups Branch and Local changes; selecting a file opens VS Code’s familiar side-by-side editor. Files changed in both scopes appear in both groups, so the comparison is explicit.

Recommended: fast overview, low visual noise, native editor features.
