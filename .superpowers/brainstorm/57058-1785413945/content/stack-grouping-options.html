Repository-first hierarchy

Each worktree is a stable top-level group with its own base branch and Branch/Local sections. The same path can appear in both sections when it has both kinds of changes.

Recommended: matches how people reason about a multi-repo stack and keeps repository-specific base branches obvious.

Change-scope-first hierarchy

Branch and Local are the top-level groups, then repositories. It makes “what is uncommitted?” very fast to scan, but repeats repository names and hides each repo’s base context until expanded.

Click the hierarchy that feels more natural for a ticket spanning several repositories.
